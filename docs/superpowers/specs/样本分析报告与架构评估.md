## 二、共性发现

### 2.1 文档结构标准化

所有文档采用**深圳政府采购统一格式**：

```
├── 第一册 专用条款
│   ├── 第一章 招标公告
│   ├── 第二章 对通用条款的补充内容及其他关键信息
│   ├── 第三章 用户需求书
│   │   ├── 一、项目基本信息
│   │   ├── 二、★货物需求明细（实质性条款）
│   │   ├── 三、实质性条款
│   │   ├── 四、技术要求（带★号和▲号）
│   │   ├── 五、商务要求
│   │   └── 六、合同条款
│   ├── 第四章 投标文件组成要求及格式
│   └── 第五章 合同条款及格式
│
├── 深圳经济特区政府采购条例相关条款
└── 政府采购违法行为风险知悉确认书
```

### 2.2 关键标记系统

文档使用统一的标记系统：
- **★**：实质性条款，不可负偏离 → 投标无效
- **▲**：重要参数，负偏离时重点扣分

### 2.3 评分方法

普遍采用**综合评分法**：
- 价格分计算：低价优先法
- 技术分权重：通常 40-60%
- 价格分权重：通常 30-50%
- 商务分权重：通常 10-20%

### 2.4 共同关注点

| 关键词 | 平均出现次数 | 说明 |
|--------|-------------|------|
| 实质性条款 | 18次/文档 | 必须响应的条款 |
| 认证/证书 | 8次/文档 | 资质要求 |
| 业绩 | 3次/文档 | 业绩要求 |
| 人员 | 50+次/文档 | 人员配置要求 |
| 服务 | 100+次/文档 | 服务要求 |

## 三、风险点分布

### 3.1 潜在风险类别

| 风险类别 | 发现频次 | 高风险品目 |
|---------|---------|-----------|
| 认证指向性 | 高 | 家具、医疗设备、物业管理 |
| 业绩要求 | 中 | 所有品目 |
| 评分标准不量化 | 中 | 教学仪器、物业管理 |
| 人员资质过高 | 中 | 物业管理、信息技术服务 |
| 中小企业政策 | 低 | 普遍 |

### 3.2 典型风险案例

#### 案例1：认证证书指向
```
发现位置：家具类文档
原文示例：要求供应商具有 ISO9001、ISO14001 认证
风险等级：高
法规依据：不得以特定认证限制供应商
```

#### 案例2：人员资质要求
```
发现位置：物业管理类文档
原文示例：安全生产主管人员需持安全员B证，安全生产管理人员须持安全员C证
风险等级：中
说明：需判断是否超出项目实际需求
```

#### 案例3：业绩要求
```
发现位置：多个品目
原文示例：供应商同类项目业绩情况
风险等级：中
说明：需判断是否限定特定行业或地域
```

## 四、架构评估

### 4.1 现有架构合理性评估

| 架构模块 | 评估 | 调整建议 |
|---------|------|---------|
| **文档解析** | ⚠️ 需增强 | 重点加强表格解析能力 |
| **规则引擎** | ✅ 合理 | 需扩展认证证书规则库 |
| **LLM 审查** | ✅ 合理 | 需针对深圳格式优化 |
| **一致性检查** | ✅ 合理 | 可扩展跨文档检查 |
| **报告生成** | ✅ 合理 | 需支持深圳格式输出 |

### 4.2 架构调整建议

#### 4.2.1 表格解析优先级提升

**现状**：每个文档平均 15-25 个表格
**问题**：
- 嵌套表格解析困难
- 表格与上下文关联缺失
- 技术参数提取不完整

**建议**：
```python
# 优先级提升到 P0
class TableParser:
    """增强表格解析"""
    - 嵌套表格识别
    - 表格标题自动关联
    - 跨表格数据一致性检查
```

#### 4.2.2 深圳格式适配

**现状**：文档采用深圳特有的格式和条例
**问题**：
- 地方性法规引用（深圳经济特区政府采购条例）
- 特有的章节结构
- 特有的标记系统（★、▲）

**建议**：
```yaml
# 新增深圳适配模块
knowledge/
├── regional/
│   ├── 深圳/
│   │   ├── 深圳经济特区政府采购条例.md
│   │   ├── 深圳经济特区政府采购条例实施细则.md
│   │   └── 评分标准格式.yaml
```

#### 4.2.3 认证证书规则库扩展

**现状**：仅设计了基础框架
**问题**：
- 各品目认证要求差异大
- 认证指向性风险识别困难

**建议**：
```yaml
rules/certifications/
├── 管理体系认证/
│   ├── ISO9001.yaml      # 通用
│   ├── ISO14001.yaml     # 通用
│   ├── OHSAS18001.yaml   # 与ISO45001关系
├── 行业认证/
│   ├── 医疗设备/         # 如ISO13485
│   ├── 物业管理/         # 如ISO55001
│   └── 家具/             # 如环境标志产品认证
```

#### 4.2.4 评分标准解析

**现状**：未作为独立模块设计
**问题**：
- 评分因素提取不完整
- 权重计算逻辑缺失

## 五、结论

### 5.1 架构整体评价

**现有架构设计合理**，但需要针对实际样本进行以下调整：

1. **P0 优先级调整**：
   - 表格解析能力增强
   - 深圳格式适配模块
   - 认证证书规则库

2. **P1 优先级调整**：
   - 评分标准解析模块
   - 地方性法规支持扩展

3. **P2 考虑事项**：
   - 跨品目一致性检查
   - 历史文档版本对比

### 5.2 实施建议

| 阶段 | 任务 | 建议时间 |
|------|------|---------|
| Phase 0 | 表格解析 + 深圳适配 | 2周 |
| Phase 1 | 认证规则库 + 评分解析 | 2周 |
| Phase 2 | 规则完善 + 准确性评估 | 2周 |
